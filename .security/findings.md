| RT-2026-07-30-02 | medium | scripts/preserve-build.js:239-252 and :386-428 | fixed-pending-verification | 2026-07-30 | Remotely-triggerable destruction of the deploy repo's git history. `main()` backs up `.git`/`CNAME`/`.nojekyll` out of `outDir` (`../silassentinel.github.io/`, a real git repo) into `.temp-preserve`, then calls `runAstroBuild()`, which shells out to `astro build`. REPRO: in the scratch replica, add a recipe with `tags: ["Savory", "../../../../PWNED-TRAVERSAL"]`, seed `out/.git/HEAD`, `out/CNAME`, `out/.nojekyll`, run `npx astro build`; build exits 1 with `Caught error rendering /tags/../../../../PWNED-TRAVERSAL: Missing parameter: tag` and `out/.git`, `out/CNAME`, `out/.nojekyll` are all gone.
